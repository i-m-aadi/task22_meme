# Meme Generator

A simple and responsive **Meme Generator** built using **HTML5, CSS3, JavaScript, and the HTML5 Canvas API**.

Users can upload an image, add customizable top and bottom text, style the text, preview the meme in real time, and download the final meme as a PNG image.

## Features

- Upload an image from your device
- Add editable top and bottom text
- Real-time meme preview
- Customize text font
- Customize text size
- Customize text color
- Customize text outline color
- Customize text outline width
- Automatic text wrapping for long text
- Download the generated meme as a PNG image
- Reset all settings with one click
- Responsive design for desktop, tablet, and mobile
- No external libraries or frameworks required

## Technologies Used

- HTML5
- CSS3
- JavaScript
- HTML5 Canvas API
- FileReader API
